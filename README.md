# 📈 Аудит та Оптимізація Асортименту E-commerce (Ніша: Рукоділля)

## 🎯 Стратегічний Фокус

Комплексний аудит товарного асортименту інтернет-магазину рукодільних товарів з метою **оптимізації управління запасами, підвищення операційної ефективності та розробки рекомендацій для максимізації комерційного потенціалу** ключових категорій.

**Статус проєкту:** Завершено (Аналіз станом на 30.09.2025 р.).

---

## 🔎 Бізнес-Виклик

Інтернет-магазин має **широкий та глибокий асортимент** (понад 26 тис. позицій, 300+ брендів), що свідчить про глибоку експертизу в ніші. Проте, неструктурованість даних та операційні проблеми заважають ефективному управлінню каталогом та максимізації продажів:

1.  **Проблема з якістю даних (Data Quality):** Низька заповненість критичних атрибутів у ключових категоріях («Аксесуари», «Нитки»), а також наявність **215–217 товарів**, нещодавно доданих на сайт, які не мають фото та детальних характеристик.
2.  **Неунікальність ідентифікаторів:** Код товару на сайті **не є абсолютно унікальним** і часто відсутній у критичних категоріях, таких як «Подарункові сертифікати» (38%) та «Схеми для вишивання хрестиком» (23%).
3.  **Неоптимальне управління запасами:** Майже половина товарів (49,7%) відсутні в наявності. Категорії «Алмазна вишивка» та «Все для в'язання і валяння» мають 0% та 1% товарів у наявності відповідно, що свідчить про необхідність рішення щодо їх ліквідації.

## 💻 Технічна Реалізація та Методологія (Python Stack)

Аналіз проведено з використанням **Python**, що дозволило вирішити складні завдання з очищення та трансформації даних.

### 1. Збір та Структурування Даних

*   **Формат даних:** Інформація завантажена у **довгому форматі (long format)**, де кожен атрибут (Розмір, Вид, Колір) відображається окремим рядком, що є оптимальним для обчислень, масштабування та автоматичних візуалізацій.
*   **Створення базового набору даних:** Встановлено, що в довіднику міститься 26612 унікальних товарів.

### 2. Пайплайн Очищення Даних (Data Cleansing Pipeline)

Для забезпечення точності аналізу розроблено багаторівневу систему очищення даних:

*   **Уніфікація назв атрибутів:** Створено спеціальний **мапінг** для уніфікування назв атрибутів та усунення дублювання.
*   **Очищення значень:** Створено **словники для буквальних та regex-замін** і розроблено **пайплайн** для очищення значень по всім атрибутам.
*   **Спеціалізована функція для розмірів:** Реалізовано функцію для виділення значень розміру (наприклад, «Розмір 30 см.») з назви атрибута та перенесення їх у відповідну колонку.
*   **Оцінка якості даних:** Розроблено **функцію для розрахунку % заповнення атрибутів** у межах категорій.
*   **Обробка ціни:** Існуюча колонка ціни була упорядкована для створення нових колонок: нова ціна, % знижки, стара ціна та валюта.

## 📊 Ключові Бізнес-Інсайти

### Асортимент та Запаси

*   **Ядро асортименту:** Основними категоріями, які формують попит, є «Нитки для вишивання» (36,5% серед наявних) та «Набори для вишивання хрестиком» (16%). «Нитки для вишивання» мають високу наявність (83%).
*   **Операційний ризик:** 215–217 товарів були нещодавно додані, але не мають заповнених характеристик і фото.
*   **Прогалини в даних:** «Аксесуари» потребують заповнення Розміру (35% заповнення), Призначення (24%) та Матеріалу (19%), а «Нитки для вишивання» — Довжини (50%).

### Цінова Політика та Прибутковість

*   **Нестабільний розподіл цін:** Розподіл ціни демонструє сильну правосторонню асиметрію (**skewness = 30.52**), що свідчить про велику кількість дешевих товарів та наявність поодиноких, дуже дорогих пропозицій.
*   **Преміум-сегмент:** Категорії «Аксесуари та інструменти для рукоділля» та «Тканина для вишивання» мають значний розкид цін і велику різницю між середньою (435 грн.) та медіанною (224 грн.) ціною, що вказує на наявність дорогих, високомаржинальних моделей (наприклад, станки Velke Potoky).
*   **Комерційна ефективність:** Категорія «Нитки для вишивання» демонструє **високу комерційну ефективність** у середньому ціновому сегменті з чітким піком масового попиту.
*   **Типові профілі:** Ідентифіковано типові профілі товарів, які можуть бути основою для автоматичних рекомендаційних систем: Набір Dimensions на білій тканині 14 каунт; Нитки DMC арт. 117, зелено-салатового кольору.

## 🚀 Рекомендації для Бізнесу (Actionable Recommendations)

### I. Оптимізація Операційної Ефективності та Якості Даних

1.  **Уніфікація ідентифікаторів:** Провести **заміну або уніфікацію коду товару на стабільний SKU** для усунення проблем з неунікальністю та відсутністю даних.
2.  **Пріоритетне заповнення даних:** Терміново пріоритезувати заповнення атрибутів у «Аксесуарах» (Розмір, Призначення) та «Нитках для вишивання» (Довжина) для **покращення SEO та фільтрації**.
3.  **Контроль нових надходжень:** Оперативно додавати фото та характеристики до **215–217 нових товарів**.

### II. Асортиментна та Цінова Політика

1.  **Управління запасами ядра:** Забезпечити **максимальну стабільну наявність** товарів у категоріях «Нитки для вишивання» (36,5%) та «Набори для вишивання хрестиком» (16%).
2.  **Розвиток преміум-сегменту:** Активно просувати товари з високою медіанною ціною (станки Velke Potoky, набори Rimma`Studio).
3.  **Виведення неактуальних категорій:** Ухвалити рішення про **виведення або відновлення запасів** у категоріях з майже нульовою наявністю («Алмазна вишивка», «Все для в'язання і валяння»).
4.  **Промоційна активність:** Активніше використовувати знижки (зараз лише 81 товар має знижку), особливо в категоріях зі стабільним попитом.

### III. Маркетинг та Персоналізація

1.  **Покращення UX:** Використати ідентифіковані типові профілі товарів та деталізовані атрибутивні зрізи **для створення цільових лендингів, автоматичних рекомендаційних систем та покращених фільтрів** на сайті.
